# Personal page category hub

## Goal
Replace the long flat MoreTab list with the selected compact category hub while preserving every existing control, destination, bilingual label, and account action.

## Build
- Keep the existing profile summary at the top, restyled to match the selected Outfit/Figtree, green-neutral direction.
- Add four clear category tiles: Profile & Health, Connections, Guides, and App Settings.
- Open each category as a focused in-page view with a back control and logically grouped existing options.
- Keep Premium visible on the main page, with Support and account actions in a compact lower section.
- Preserve guest, premium, admin, dark mode, language, text size, notifications, AI chat, redeem, connected apps, and deletion states.
- Use the existing semantic color tokens and Button controls; update typography tokens to Outfit and Figtree.

## Verification
- Check guest and signed-in layouts at mobile and desktop widths.
- Verify category navigation, toggles, dialogs, and back behavior.
- Confirm the preview builds without errors and the page has no clipped or overlapping content.
